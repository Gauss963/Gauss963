Verbatim: A Local macOS App for Audio and Video Transcription

Posted on 2026-06-21 · Keywords: macOS app, Transcription, Whisper, Offline

I recently built Verbatim, a native macOS transcription app that runs Whisper locally and turns audio or video files into readable transcripts without sending media to a cloud service.

The idea behind Verbatim is simple: transcription should feel fast, private, and native. Instead of uploading files to a remote server, Verbatim keeps everything on the Mac itself. You drop a file into the queue, choose a language, start the run, and review the result in a transcript view designed for reading and playback side by side.

Why I Built It

A lot of transcription tools are convenient, but they also assume you are willing to upload recordings somewhere else. That is not always ideal, especially when the source material is personal, research-related, or simply large enough to make cloud workflows annoying. I wanted something that behaved more like a real Mac app: local files in, local results out, and no unnecessary friction in between.

Verbatim is built in SwiftUI and uses Whisper large-v3 locally, so the app is intentionally opinionated. It prioritizes privacy, offline use, and a focused interface over an everything-and-the-kitchen-sink feature list.

What Verbatim Can Do

  • Run Whisper large-v3 locally on macOS.
  • Accept both audio and video files through drag and drop or the file picker.
  • Support language selection for Auto, Chinese, and English.
  • Show queue state, run progress, and failure status clearly.
  • Provide a large, readable transcript view with copy support.
  • Sync playback with highlighted transcript segments.
  • Show video preview when the source file is a video.

Supported Media Formats

The current build accepts common formats including .mp3, .mp4, .m4a, .wav, .aiff, .aif, .mov, .aac, and .flac.

Download

Direct download: Verbatim-macOS-arm64-v1.0.2.zip

Package note: The app bundle includes the Whisper large-v3 model, so the zip is large.

If macOS Blocks the App on First Launch

This build is currently distributed without Apple notarization, so macOS may block it the first time you try to open it. If that happens, you can still run it manually through System Settings.

How to open it anyway:

  1. Unzip Verbatim-macOS-arm64-v1.0.2.zip.
  2. Try opening Verbatim.app once so macOS shows the warning.
  3. Open System Settings and go to Privacy & Security.
  4. Scroll down until you see the message saying Verbatim was blocked from opening.
  5. Click Open Anyway and confirm in the next dialog.

If you prefer, you can also Control-click the app in Finder and choose Open. In practice, the important idea is the same: macOS needs one manual confirmation before the app is allowed to run.

Current Direction

Right now Verbatim is focused on the core local transcription experience: import media, run Whisper, read the transcript, and follow playback. There is still room to improve signing, release automation, and progress feedback, but even in its current form it already does the part I care about most: making local transcription on macOS feel practical and pleasant.
