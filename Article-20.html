SCEC TPV101 Tatva vs. UGUCA vs. SPECFEM3D (standard mesh 100m)

Posted on 2026-08-12 · Keywords: Simulation, SCEC, TPV101, Tatva, UGUCA, SPECFEM3D

A validation log comparing Tatva against UGUCA and SPECFEM3D for the SCEC TPV101 benchmark using the standard 100 m mesh, with rupture-time, fault-station, accuracy, and runtime results shown directly from the PDF outputs.

Methods

UGUCA

UGUCA uses the spectral boundary integral method to simulate dynamic and quasi-dynamic rupture propagation along a weak interface between two semi-infinite half-planes.

SPECFEM3D

The SPECFEM codes use the spectral-element method to simulate seismic wave propagation across different scales. Together with dedicated inversion tools, they form a computational-seismology ecosystem for topics including seismic tomography and ground-shaking hazard analysis.

Tatva

Tatva is a pure Python finite-element library built on the JAX ecosystem, making it possible to use FEM workflows in a differentiable setting.

Error Summary

Tatva 的模擬結果與 UGUCA 相近。部分位置的 horizontal shear stress 在 t > 10 s 後沒有像 UGUCA 與 SPECFEM3D 一樣下降，反而呈現上升趨勢；不過整體結果令人滿意。

Runtime

  • 創進一號，OpenMPI，56 cores: 36:45:23, NT$207.
  • NANO4，single H200 GPU: 03:45:23, NT$113.

CPU 與 GPU 的模擬結果沒有差異；使用 MPI 與不使用 MPI 的結果也沒有差異。

Conclusion

  • Tatva + RSF 的結果可用，後續將套用至 PMMA 模擬。
  • 相較於 CPU，GPU 模擬不僅更經濟，也明顯更快。
